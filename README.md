# HMM_KunitzDomain  
### Profile Hidden Markov Model for Kunitz-Type Protein Domain Identification

---

## Overview
This repository contains a bioinformatics workflow for identifying **Kunitz-type (BPTI) protein domains** using a **Profile Hidden Markov Model (HMM)**.

The project focuses on:
- organizing raw and processed protein sequence datasets,
- constructing a domain-specific HMM from curated sequences,
- evaluating the model on positive and negative datasets.

The repository is designed for **educational and research use**, with an emphasis on clarity, reproducibility, and good data-management practices.

## Data Organization

Raw Data (Data/Raw):
This directory contains source datasets that are not generated by the pipeline.
These files represent the starting point of the analysis and are kept unchanged.
Examples include:
- collections of Kunitz-domain sequences,
- organism-specific subsets,
- negative datasets derived from external annotations.

Processed Data (Data/Processed):
This directory contains derived artifacts produced from the raw data, including:
- curated and non-redundant sequence sets,
- multiple sequence alignments,
- trained HMM profiles,
- positive and negative datasets used for evaluation.
- Files in this directory are used directly for model training and testing.

## Objectives

- Build a profile HMM that captures conserved features of the Kunitz domain
- Apply the model to distinguish Kunitz-domain sequences from non-domain sequences
- Evaluate classification performance using positive and negative datasets
- Maintain a clean and reproducible data layout


## Requirements

The workflow assumes availability of standard bioinformatics tools:
Python ≥ 3.8
HMMER ≥ 3.x
Optional tools used during dataset preparation may include:
CD-HIT (sequence redundancy reduction)
External alignment or structural analysis tools

## Methodology

1. Dataset Preparation
Protein sequences were collected from public databases and organized into raw datasets.
Filtering and curation steps were applied to generate processed datasets suitable for modeling.
2. Multiple Sequence Alignment
Curated Kunitz-domain sequences were aligned to highlight conserved positions relevant for domain identification.
